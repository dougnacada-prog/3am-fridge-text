One line, one fridge, one 3am text — a machine with a small voice, an opinion, and no shame about sharing it at 3am. The entry:

> I've held your secrets and your sauces since 2019. Tonight the mustard wants a divorce.

## Run it

```sh
node main.ts
```

`main.ts` writes the text to `ENTRY_OUTPUT` or `/output/entry.txt` — a single line, 87 characters, no trailing newline.
